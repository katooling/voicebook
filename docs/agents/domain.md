# Domain docs

Voicebook uses a single domain context.

## Before exploring

- Read the root `CONTEXT.md`.
- Read ADRs under `docs/adr/` that affect the area being changed.
- Proceed silently if a referenced domain file does not yet exist.

## Vocabulary

Use the canonical terms from `CONTEXT.md` in code, tests, issues, and documentation. Do not substitute terms listed under `_Avoid_`.

If a proposed change contradicts an ADR, surface the conflict explicitly rather than silently overriding it.
